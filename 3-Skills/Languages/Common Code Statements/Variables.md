## What are Variables?

^4063f9

1. Variables are containers similar to a box that stores values, especially values based on the input of a user.
2. Variables can be reused again later in an app or program. 
3. Variables can declare a value but can also be used to declare a “new” value using the same variable name. 
4. Variables can be written as snake case (variable_name). 
5. Variables can be written as camel case (variableName)

### Keywords: 
1. Containers 
2. Box 
3. Variables 

---
## When would Variables be used for in programming or an app?

Variables are the main part of the codebase that store values that are inputted by the user in the programmer for every application or program. 

**Variables** are the reference name given to a value in your code.
Basically, you give a name to a value using variables.


---
## Example Problem

Variable not declared or assigned a value:

> var1 

Variable declared and assigned a value:

> var1 = value 



---
## Notes

- Don't start variables with a number. 
- Variables should not have spaces in between them when there are multiple names used for a variable. (ex. this here = "will have an error unlike this_here = "no error)
