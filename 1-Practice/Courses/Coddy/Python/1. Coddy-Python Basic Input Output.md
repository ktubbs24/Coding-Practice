## 📝 Overview

- **Input** → getting data from the user (with `input()`)
    
- **Output** → showing data back (with `print()`)


---
## 🔑 Key Concepts

- User input from outside the program would go inside the parenthesis in the input( ). 
- Inputs no matter the input always results as a string type (so string need to be converted or [[Python-Caste]] in  order to do arithmetic operations). 




---
## ⚛️ Code

```python
variable = input("This is the input of someone:")
print(variable)
```

For example, for input `25`, the expected output is `"95 years till 120"`.

## Recap

Write a program that gets an input from the user, a number, `1` or `0`.

The program will output `"T"` if the input is 1 and `"F"` otherwise.

> Remember! you can cast the input to number using `int()`

### Practice code

```python
# Input from someone to see if they like the color blue. 

# 1st try: 
blue = int(input(1)) # If you pass a number like 1 directly to input(), Python will treat it as an error because it expects a string. So, you’d want to use a descriptive string to prompt the user to enter 1 or 0
# blue = 1
if blue = 1: # In Python, to check if two values are equal, you use ==. The single = is for assigning a value to a variable, not for comparing.
	blue = "T"
else if blue = 2: # Python uses elif instead of else if for additional conditional checks. If you’re using else if, it will cause a syntax error.
	blue = "F"
else: 
	print("Enter a number: 1 or 0")
print(blue)

# 2nd try: 
blue = int(input("Enter a number 1 for True or 0 for False: "))
if blue == 1:
	blue = "T"
elif blue == 0: 
	blue = "F"
else: 
	print("Enter a number: 1 or 0") # Your else branch correctly prints an error message ("Enter a number: 1 or 0") when the input isn’t 1 or 0. However, after printing this message, the code still prints the value of blue. If the user enters something invalid (like 2 or a letter), consider what blue’s value will be and whether printing it makes sense.
print(blue)

# 3rd try: 
blue = int(input("Enter a number 1 for True or 0 for False: "))
if blue == 1:
	blue = "T"
elif blue == 0: 
	blue = "F"
elif blue !== 1 or 0: # - n Python, or 0 doesn’t work as expected in this context. The or operator evaluates to a boolean, but 0 is always considered False in Python, and the expression is ambiguous. You likely want to check if blue is neither 1 nor 0 (e.g., blue != 1 and blue != 0). **Hint**: For the condition, think about how to express “blue is not 1 and not 0” clearly. You might need a logical operator like and to combine conditions. Also, ensure you’re using != instead of !==.
	print("Enter a number: 1 or 0")
else: 
	print(blue)
````
