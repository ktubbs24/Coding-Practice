## 🧠 Learnings


How do you access the value stored in a variable?: By calling the variable name. #card #card/variables 

---
**Arrays** are a combination of multiple same or different values.

---
In Python, we initiate an array with `[]`, and inside these array brackets, we put the values separated with a comma.

---
For example the following array contains `strings` (because every element inside that array starts with `'` and ends with `'`),

```python
arr = ['a', 'b', 'c']
```

Another example is an array of `integers`

```python
arr = [1, 2, 3]
```

---
You can also have different types of values in the same array. Like,

```python
arr = ['a', 1, 'b']
```
