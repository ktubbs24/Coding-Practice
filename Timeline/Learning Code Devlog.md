- Example 
	- 2 ** 3 is just like saying 2 to the third power (since the 3 superscript can't be written in code like how it can on paper).

Reminder about Exponentiations in Python
`print(-3**2) `is not the same as `print(-(3**2))` but both will give the same result it will just give it differently depending on how the operation is set up inside of the print function because: 

- python will perform the operation first that is inside of the print parenthesis and then make it negative for `print(-3**2)` giving the answer of 9 first and then -9 
- but when we put a parenthesis to make the operations solve first and then make it negative like this `print(-(3 ** 2))` then the answer is -9 by default 
- to get the result of 9 using this will work `print((-3)**2)`.

What the result of print(2 ** 3 ** 2) be:
