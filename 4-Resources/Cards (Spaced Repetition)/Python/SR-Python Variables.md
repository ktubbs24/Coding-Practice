## Something to remember about inputs and strings in Python 

Why is it important to use `int()` or `float()` on a user's input in python? #card #card/variables/python #card/syntax/python

User input is always read as a **string** by default. To perform mathematical operations like addition or multiplication, you have to **cast** or **convert** the input into a number using `int()` (for whole numbers) or `float()` (for decimals).
