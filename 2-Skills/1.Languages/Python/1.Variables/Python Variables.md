## What are Python-Variables?

![[Variables#What are Variables?]]

Python variables, for the most part, are basically similar to regular variables of programming syntax. Python, however, focuses more on snake_case within the names of variables that have more than one word in the name of the variable. 
- see also: [[Python-Syntax]]

---
## When would Python-Variables be used in programming or an app?

Python variables will be used in programming or an application to store information or data from a user input or for just any type of data that I want to have stored to make the program run. 

An example of which is if somebody were to enter their name, their name would be stored as a value in the container of a variable. 

```python 
var1 = "John" # this is only good for if I want var1 to always be the word "John" And it will remain as such unless I were to redeclare var1 at a later time, but this would omit user input. 
```
