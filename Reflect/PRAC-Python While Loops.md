# 💻  Practice Examples 
## 🧪 Writing a while loop program 

Write a program that gets one input, float number.
Use a while loop to divide the input by 3 as long as the number is bigger or equal to 2.5.
Print the first number that is smaller than 2.5.
### First and Final Attempt!!! 🎉 [[2025-09-04]]
```python
number = float(input( ))
while number >= 2.5:
    number /= 3
print(number)
```

### 🧪Code Review in detail: 
---
#### Line-by-Line Analysis

**Line 1: `number = float(input( ))`
   - Explanation: The variable `number` is declared with a value based on the user input. 
   - Details: The input is casted with float because the input is expected to be a decimal number and stored in the variable: number 
   - Potential pitfalls: TypeError if input is function is present in an online IDE versus entering within Coddy’s environment. Within an online environment just enter this line as:
     `number = ( ) ` or as `number = ` or as `number = float( )`

**Line 2: `while number >= 2.5:`
   - Explanation: This is where the while loop begins to compare if the input from the user is greater than or equal to 2.5. 
   - Details: Input is compared with 2.5 as a condition. 
   - Potential pitfalls: none I can think of. 


**Line 3: ` number /= 3`
   - Explanation: if the condition is met in line two based on the user input, then line three is the code that is executed here. 
   - Details: based off of the user's input, whatever number the user inputs into the input function will be divided by 3 and then stored within the number: variable. 
	   - Another way this could have been written is: 
		   - number = number / 3
   - Potential pitfalls: if I just wrote this line as 
	   - "number = 3" then the program would t run correctly because the input would be equated to the number 3. No operation would happen.
	   - “number / 3” the program would not run correctly as expected based off of the instructions because after the input would divide into the number 3, it would just leave the answer. It wouldn't be stored in the variable:number. 


**Line 4: `print(number)`
   - Explanation: the newly declared `number`  that stores the result of the code from the previous step is printed to the screen but it's printed only after the condition in the program cannot be met. 
   - Details: the number variable prints the first input that is injected into the program that is less than 3.5. 
   - Potential pitfalls: I had realized yesterday when I had a common code just like this one that if the print statement was indented to fit directly under the previous line (line 3), then the result of the code output will be printed to the console. But by the print statement being outdented, it means that it is outside of the execution. So, the print statement only prints if the while loop stops.
