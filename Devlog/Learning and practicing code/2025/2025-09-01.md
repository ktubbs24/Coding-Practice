To print something in python, we use the `print()` function.

Inside this parenthesis `()`, we can put the value that we want Python to print.

For example,

```python
print("hello world")
```

We want to print a string value that's why we used `" "` to wrap the phrase.

---

**Variables** are the reference name given to a value in your code. #saved

Basically, you give a name to a value using variables.

---
In Python, there are two types of numbers values:- #saved

- `int` - all the numbers, without decimals. e.g. 5, -3, 0, 1, 10, etc.
- `float` - all the numbers, with decimals, 3.2 or -1.03

---
String Value is the combination of one or more characters written between single quotation mark or double quotation mark. #saved

**Single Quotation Mark**

```python
a = 'Learn Python'
```

**Double Quotation Mark**

```python
a = "Learn Python"
```



Both the codes are correct.
