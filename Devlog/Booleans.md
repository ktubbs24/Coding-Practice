## What are Booleans?

**Boolean** simply means either `True` or `False`.



Storing a Boolean value in a variable is no different than numbers and strings.



### Keywords: 
1. 
---
## When would Booleans be used in programming or an app?

Booleans are values that are used to give a decision in conditional statements such as True or False. 




---
## Example Problem

Boolean values are stored like this:

```python
a = True
```

or,

```python
a = False
```

There are only two Boolean values i.e. `True`, `False`.
