## String Values 
String Value is the combination of one or more characters written between single quotation mark or double quotation mark.

**Single Quotation Mark**

```python
a = 'Learn Python'
```

**Double Quotation Mark**

```python
a = "Learn Python"
```

Both the codes are correct.

> *Strings can consist any and all kinds of characters, including **Alphabets**, **Numbers**, and **Special Characters**.
